🤖 Téléphone Android

  1. Ouvrez le logiciel dans Chrome.
  2. Touchez ⋮ (en haut à droite).
  3. Touchez Installer l'application (ou « Ajouter à l'écran d'accueil »).
  4. Confirmez : l'icône apparaît sur l'écran.

🍎 iPhone / iPad

  1. Ouvrez le logiciel dans Safari.
  2. Touchez le bouton Partager (carré avec une flèche ↑).
  3. Touchez Sur l'écran d'accueil.
  4. Touchez Ajouter.

💻 Ordinateur (PC)

  1. Ouvrez le logiciel dans Chrome ou Edge.
  2. Cliquez sur l'icône ⊕ Installer au bout de la barre d'adresse (ou ⋮ → Installer).
  3. Cliquez Installer : l'icône va sur le bureau et dans le menu Démarrer.

Le logiciel a toujours besoin d'internet pour enregistrer. Sans connexion, l'application affiche un message clair au lieu d'une page d'erreur.
